This is a very simple tool for organizing large amounts of image and video files, moving them from one folder into other folders assigned to numbers.

First, select the folder containing the photos and videos that you want to move, then assign target folders to numbers.

When you press a number, the photo or the video that you are viewing moves to that target destination and the next photo or video is shown automatically.

You can skip to the next photo using the arrow keys, and delete a file with the Delete key.

It remembers the folders you assigned in the config.json file.

It can play mp4 and webm videos. The videos loops by default.

You can select multiple files in the gallery view.

It can also play GIF files.

"R" key rotates the image 90 degrees clock-wise.

I created this program using ChatGPT Codex and Gemini.

I moved thousands of photos from my phone to my PC. Most of the photos were in a limited number of categories, for example: memes, photos of me, buildings, nature, animals, infographics, and art. Previously it took me hours to move photos into the correct folders. This tool cuts that time to about one quarter, so I recommend it if you’re dealing with lots of photos.
